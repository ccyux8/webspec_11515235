## 2. 技術邊界與外部依賴 (Technical Boundaries)

1. **結構與腳本**：
   - 採用標準 HTML5 語義化標籤（`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`）。
   - 採用內嵌式 CSS（`<style>`）與原生 JavaScript（`<script>`），確保離線與單機環境均可順暢執行。
2. **字體資源（Google Fonts CDN）**：
   - `Noto Sans TC`：繁體中文主字體（300 / 400 / 500 / 700 / 900）。
   - `Montserrat`：英文輔助標題與導覽字體（400 / 600 / 700 / 800 / 900）。
   - `Syne`：數據數字與性能指標專用展示字體（700 / 800）。
3. **向量圖形與無圖依賴**：
   - 全站無須外掛未授權的點陣圖片檔；坐騎造型、閃電圖標、幾何光環均採用純 **SVG 向量標籤** 與 **CSS 漸層濾鏡** 繪製，具備高清晰度與秒開優勢。
4. **Web Audio API**：
   - 使用瀏覽器原生 `AudioContext` 振盪器（Oscillator）與低通濾波器（BiquadFilter）合成恐龍低頻咆哮音效，無須依賴外掛音訊檔案。

- 點擊 `#btnRoar` 執行：
  1. 初始化 `new AudioContext()`。
  2. 建立 `OscillatorNode`（類型 `sawtooth`），頻率由 `220Hz` 於 1.2 秒內以指數曲線驟降至 `45Hz`。
  3. 連接 `BiquadFilterNode`（`lowpass`，截斷頻率 `400Hz`）模擬胸腔共鳴震動。
  4. 連接 `GainNode` 控制漸強至 0.6 再衰減至 0.001。
  5. 播放時限 1.5 秒，並顯示震撼通知 Toast。
